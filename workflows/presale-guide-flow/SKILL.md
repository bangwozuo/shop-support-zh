# 售前智能导购

按固定 DAG 编排多个原子技能，完成「意图识别 → 知识库检索 → 议价判定 → 汇总交付」的端到端售前接待。触发方式：事件（买家消息）。

## 能力描述

识别买家意图，在知识库内作答并盘点缺口，对议价诉求匹配授权内让步档位，最终汇总成导购台账与报告，供客服/店长直接使用。

## 编排的原子技能

| # | 原子技能 | 能力 |
|---|---------|------|
| 1 | [商品知识库问答](../../skills/product-kb-qa/) | RAG 检索 + 口径一致应答 |
| 2 | [议价话术](../../skills/price-negotiation-script/) | 价格异议处理、底线内让步 |

## 步骤明细

| # | 步骤 | 技能资产 | 输入 | 处理 | 输出 | 失败处理 |
|---|------|---------|------|------|------|---------|
| 1 | 意图识别 | `presale-guide-flow`（内置规则） | 买家消息 | 按词表判意图：议价/物流/售后/商品咨询/其他 | 意图标签 | 无法归类→标「其他」，不阻断后续 |
| 2 | 商品知识库问答 | `../../skills/product-kb-qa/` | 买家问题 + kb | 打分检索，阈值 0.35 | 命中答复 + 置信度 / 知识缺口 | 未命中→记缺口，**不编答案** |
| 3 | 议价话术判定 | `../../skills/price-negotiation-script/` | 议价问题 + 订单金额 | 按金额档位匹配让步与底线 | 让步档位 + 升级建议 | 缺金额→标「未知金额」，转人工定档 |
| 4 | 汇总交付 | `presale-guide-flow`（内置） | 上一步输出 | 汇总台账 + 报告 | 导购台账.xlsx + 报告.md | 单步失败→保留已完成步骤并标注 |

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `kb` | array | ✅ | 店铺知识库条目（同 product-kb-qa 格式） |
| `buyers` | array | ✅ | 买家咨询数组，每项含 `买家`/`问题`/`订单金额`(可选) |
| `min_score` | number | ⬜ | 知识命中阈值，默认 `0.35` |

## 输出规格

| 字段 | 类型 | 说明 |
|------|------|------|
| `summary` | object | 咨询总数 / 知识命中 / 知识缺口 / 命中率 / 议价条数 / 意图分布 |
| `steps` | array | 分步结果（含状态与失败处理） |
| `deliverable` | string | 端到端交付物：导购台账.xlsx + 售前导购报告.md |

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| 缺 `kb` 或 `buyers` | 列出缺失字段并终止，输出提示 |
| 知识未命中 | 记入知识缺口清单，不臆测作答，继续处理下一条 |
| 议价缺订单金额 | 标「未知金额」，不套用档位，转人工定档 |
| 中间步骤输出不完整 | 保留已完成步骤结果并显式标注，不静默 |
| 提示词被平台截断 | 拆分批次，分两次处理 |

## 调用示例

**输入**（`examples/input.json` 节选）：

```json
{"kb": [{"id": "KB-06", "类目": "参数", "问题": "蓝牙耳机续航多久",
         "关键词": ["续航", "充电", "电量", "能用多久"], "答案": "单次充电续航 8 小时…"}],
 "buyers": [{"买家": "买家A", "问题": "这个耳机充一次电能用多久？"}]}
```

**输出**（实跑，6 条咨询命中率 66.7%）：

| # | 买家 | 意图 | 知识条目 | 匹配度 | 议价档位 |
|---|---|---|---|---|---|
| 1 | 买家A | 商品咨询 | KB-06 | 0.632 | — |
| 3 | 买家C | 议价 | 未命中 | 0.138 | 50–200 元 |
| 5 | 买家E | 议价 | KB-08 | 0.688 | 50–200 元 |

知识缺口：`能不能刻名字定制`（知识库无对应条目）。
