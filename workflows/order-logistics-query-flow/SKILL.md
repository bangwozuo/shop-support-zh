# 订单/物流自动查询

按固定 DAG 编排，完成「单号识别 → 物流接口 → 状态解读回复」的端到端查件。触发方式：事件。

## 能力描述

从买家消息识别运单号，解析轨迹为六态、计算停滞时长、挑出异常件，并按状态生成可直接发送的回复与「需主动介入」清单。

## 编排的原子技能

| # | 原子技能 | 能力 |
|---|---------|------|
| 1 | [物流跟踪解读](../../skills/logistics-track-parse/) | 物流节点翻译 + 异常预警 |

## 步骤链路（DAG）

```mermaid
flowchart LR
    IN["买家查件消息"] --> S0["单号识别"]
    S0 --> S1["物流跟踪解读"]
    S1 --> S2["状态解读回复"]
    S2 --> S3["汇总交付"]
    S3 --> OUT["台账 + 回复"]
```

## 步骤明细

| # | 步骤 | 技能资产 | 输入 | 处理 | 输出 | 失败处理 |
|---|------|---------|------|------|------|---------|
| 1 | 单号识别 | `order-logistics-query-flow`（内置） | 买家消息 + shipments | 正则抽取运单号 | 运单号列表 | 识别不到→让用户发运单号，不猜测 |
| 2 | 物流跟踪解读 | `../../skills/logistics-track-parse/` | 运单轨迹 + now | 归一化六态、算停滞、挑异常 | 状态 + 异常类型 | 无轨迹→标「无轨迹」，提示核对单号 |
| 3 | 状态解读回复 | `order-logistics-query-flow`（内置） | 上一步状态 | 映射分状态话术 | 回复文本 | 异常件统一走主动介入话术 |
| 4 | 汇总交付 | `order-logistics-query-flow`（内置） | 上一步输出 | 汇总台账 + 回复 | 台账.xlsx + 回复.md | — |

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shipments` | array | ✅ | 运单轨迹（同 logistics-track-parse 格式） |
| `question` | string | ⬜ | 买家的查件原话（用于单号识别） |
| `now` | string | ⬜ | 基准时间，用于算停滞 |
| `stale_hours` | number | ⬜ | 停滞阈值，默认 `72` |

## 输出规格

| 字段 | 类型 | 说明 |
|------|------|------|
| `summary` | object | 运单总数 / 识别单号数 / 正常件 / 异常件 / 待主动回复 / 基准时间 |
| `steps` | array | 分步结果（含状态与失败处理） |
| `deliverable` | string | 端到端交付物：物流查询台账.xlsx + 物流查询回复.md |

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| 缺 `shipments` | 打印 error 并退出码 1，不产出假结果 |
| 单号识别不到 | 追问买家运单号，不猜测 |
| 运单无轨迹 | 标「无轨迹」，提示核对单号或由客服查件 |
| 异常件 | 走主动介入话术，承诺 24 小时内答复 |

## 使用步骤

### 方式一：纯提示词

把 `prompt.txt` 全量粘贴为系统提示词，提供 `shipments`（可含 `question`）。

### 方式二：带脚本（真编排 + 产物）

```bash
python3 <SKILL_DIR>/scripts/run_flow.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/run_flow.py --demo
```

产物：`out/物流查询台账.xlsx`、`out/物流查询回复.md`、`out/order_logistics.json`。

## 调用示例

**输入**（`examples/input.json` 节选）：

```json
{"question": "帮我查下包裹到哪了，运单 EMS9988776655443",
 "shipments": [{"运单号": "EMS9988776655443", "承运商": "EMS", "事件": [
   {"时间": "2026-09-19 10:00", "描述": "邮件到达乌鲁木齐中心，发往喀什", "地点": "乌鲁木齐"}]}]}
```

**输出**（实跑，4 单 3 异常）：

| 运单号 | 当前状态 | 停滞小时 | 是否异常 | 异常类型 |
|---|---|---|---|---|
| SF1380001112223 | 派件中 | 13.9 | 正常 | — |
| ZTO5500987654321 | 异常件 | 88.5 | ⚠️ 异常 | 轨迹异常（退回/超区）；超 72 小时无更新 |
| EMS9988776655443 | 运输中 | 263.0 | ⚠️ 异常 | 超 72 小时无更新 |

待主动回复 3 单，回复话术取自物流技能的分状态话术库。
