## 二、示例实跑（提示词执行）

T2 为生成型资产，无脚本；验证方式为把 `prompt.txt` 全量作为系统提示词后对
`examples/input.json` 执行，人工审读输出。

**输入**：比价 + 压价（见 `examples/input.json`）
**输出**：见 `examples/output.md`

| 项 | 结果 |
|---|---|
| 议价类型识别 | 比价型 + 压价型（正确） |
| 底线校核 | 底线价 = 120×(1+25%) = 150；成交 174 > 150，未击穿 ✅ |
| 五段结构完整 | ✅（共情/诊断/价值锚定/方案/行动） |
| 禁止项检查 | 未诋毁竞品、未虚构原价、未用极限词、未引导站外交易（4/4） |
| 超授权升级 | 买家若坚持 ≤159 → 正确判为「转店长审批」 |

### 多维自检

| 维度 | 证据 |
|---|---|
| D1 领域术语 | 议价类型六分类、底线价、价值锚定、价保期、让步档位 |
| D2 具体阈值 | 金额档 <50/50–200/>200；让价 ≤5%/≤8%；价保 15 天；回复 ≤160 字 |
| D3 方法/算法 | 类型识别表 + 让步梯度表 + 底线价公式 + 五段结构 |
| D4 领域边界 | 不诋毁竞品、不虚构原价、不站外交易、未给成本不报底价 |
| D5 可交付输出 | 话术 + 议价分析表 + 升级判断表，含 `reply`/`negotiation`/`escalate` |

## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 无脚本 | 让价幅度与底线校核依赖 `context` 提供成本/毛利率；缺参时不报底价（已写进 prompt） |
| 授权因人而异 | 让步档位为默认建议值，店铺可按自身毛利结构在 prompt/`persona` 中覆盖 |
| 价保规则时效 | 各平台价保期会调整，以订单页/活动页公示为准 |

**通过。** 结构合规、prompt 深度达标；示例输出类型识别正确、底线未击穿、零违规表述，超授权情形正确升级。
