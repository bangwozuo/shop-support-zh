# 议价话术

在**不击穿底线价**的前提下把想走的买家留住。武器是**价值锚定 + 授权内的有限让步**，不是无底线降价。

不做的事：不虚假促销、不诋毁竞品、不承诺无法兑现的优惠。

## 能力描述

1. **议价类型识别**：询价型 / 比价型 / 压价型 / 威胁型 / 价保型 / 批量复购型。
2. **让步梯度**：按订单金额（<50 / 50–200 / >200 元）划分一线自主、二线审批、店长审批三档。
3. **底线守护**：底线价 = 成本价 × (1 + 最低毛利率)，任何情况不得低于底线；未给成本则不报底价。
4. **五段话术**：共情 → 诊断 → 价值锚定 → 方案（1–2 个）→ 行动。
5. **价保规则**：淘宝/天猫普通商品价保 15 天（大促以活动页公示为准），符合走平台入口补差。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `question` | string | ✅ | 买家议价消息 |
| `context` | string | ⬜ | 商品/标价/成本/最低毛利率/当前活动/竞品报价/买家历史 |
| `persona` | string | ⬜ | 店铺可承诺范围（如「一线最多让价 5%、赠品 1 件」） |

## 输出规格

- `reply`：可直接发送的话术（五段结构，≤ 160 字）
- `negotiation`：议价分析（类型 / 诉求 / 价值锚点 / 让步档位 / 底线校核）
- `escalate`：升级判断（否 / 转二线审批 / 转店长审批 + 触发原因 + 建议）

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供 `question`（议价原话），尽量补 `context`（含成本/底线/活动）与 `persona`
4. 得到话术 + 议价分析 + 升级判断

## 边界（不做的事）

- ❌ 不诋毁、贬低竞品（《反不正当竞争法》）
- ❌ 不虚构原价、不玩假活动（《价格法》）
- ❌ 不使用极限词（《广告法》第九条）
- ❌ 不承诺低于底线价的成交价
- ❌ 不引导站外交易、不发私聊收款码
- ❌ 涉及资金的让价/退款只出草稿，不执行

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "question": "老板这个耳机199太贵了吧，隔壁家同款才159，便宜点我马上拍",
  "context": "无线降噪耳机，标价 199，成本 120，最低毛利率 25%（底线 150）；活动满 199 减 20；竞品 159 为无降噪老版本",
  "persona": "一线客服，可自主用券/赠品/包邮，直接让价上限 5%"
}
```

**输出**（节选）：

| 项 | 内容 |
|---|---|
| 议价类型 | 比价型 + 压价型 |
| 价值锚点 | 主动降噪 vs 竞品无降噪；一年联保；赠收纳盒 |
| 让步档位 | 满减 -20 + 5 元券 + 赠品 + 包邮，实付 174 |
| 底线校核 | 底线 150 元；成交 174 > 150 ✅ |
| 是否升级 | 否（让价落在授权档内） |
