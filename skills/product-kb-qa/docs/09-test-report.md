## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 词典式检索 | 基于标签 + bigram，不做语义向量；同义改写的极端问法可能漏命中，需模型按 prompt 兜底 |
| 阈值可调 | `min_score` 默认 0.35，店铺可上调以提高精度、下调以提高召回 |
| 知识库时效 | 命中率随知识库更新变化，改库后须重跑脚本 |
| 多轮追问 | 脚本只做单轮；多轮上下文与口语化由模型处理 |
