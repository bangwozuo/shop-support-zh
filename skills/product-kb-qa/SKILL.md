# 商品知识库问答

在店铺**已建立的知识库范围内**回答买家问题，每条答复可回溯到知识条目 ID；知识库里没有的，明确列成缺口，不用常识补。

不做的事：不编造参数/库存/价格，不做多轮销售逼单，不承诺知识库没有的赔付。

## 元信息

| 字段 | 值 |

| 类型 | **`atomic`（原子技能）** |

| 资产形态 | 纯提示词 + 可选 Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **确定性检索**：按 `匹配度 = 0.55 × 标签最佳匹配 + 0.45 × 字面 bigram Jaccard` 打分，阈值默认 0.35。
2. **置信度分级**：高（≥0.62）/ 中（0.45–0.62）/ 低（0.35–0.45）/ 未命中（<0.35）。
3. **口径一致**：答复逐字取自知识库，标注命中条目 ID；冲突条目按更新时间择新，无法判定转二线。
4. **缺口盘点**：未命中问题 → 最相近条目 + 最高匹配度 + 缺口类型，输出可补的知识条目建议。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `kb` | array | ✅ | 知识库条目，每条含 `id`/`类目`/`问题`/`关键词`/`答案`（唯一作答依据） |
| `questions` | array | ✅ | 买家问题，每项含 `买家`/`问题` |
| `min_score` | number | ⬜ | 命中阈值，默认 `0.35` |

## 输出规格

- `summary`：问题总数 / 命中数 / 未命中数 / 命中率 / 命中阈值 / 涉及类目数
- `results`：逐条问答（买家 / 问题 / 是否命中 / 知识类目 / 匹配度 / 置信度 / 命中条目ID / 标准答复）
- `gaps`：知识缺口（问题 / 最相近条目 / 最高匹配度 / 缺口类型）

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供 `kb`（知识库条目）+ `questions`（买家问题）
4. 得到带条目 ID 的问答台账与知识缺口清单

### 方式二：带脚本（词表检索 + 产出 Excel/PNG）

```bash
python3 <SKILL_DIR>/scripts/kb_qa.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/kb_qa.py --demo            # 无输入也能看效果
python3 <SKILL_DIR>/scripts/kb_qa.py --question "什么时候发货" --kb kb.json
```

产物：

| 文件 | 内容 |
|---|---|
| `out/知识库问答结果.xlsx` | 问答结果（未命中行标红）/ 知识缺口 / 类目命中分布 |
| `out/类目命中分布.png` | 各类目命中数量柱状图 |
| `out/kb_qa.json` | 机器可读结果，供智能体读取 |

**分工**：脚本做**确定性检索与打分**（不漏、可复现）；模型做**口语化、共情、缺口建议**（脚本做不了的）。答复话术中的数值以脚本输出为准。

## 边界（不做的事）

- ❌ 不编造知识库之外的参数、库存、价格、活动、到货时间
- ❌ 不把未命中问题当命中作答 —— 这是客服致差评的首要原因
- ❌ 不承诺无法兑现的赔付/补偿，涉及资金只出草稿不执行
- ❌ 不泄露买家个人信息
- ❌ 知识库口径多变，本答复**不能替代**店铺最终定价与售后政策

## 调用示例

**输入**（`examples/input.json`，节选）：

```json
{
  "min_score": 0.35,
  "kb": [
    {"id": "KB-06", "类目": "参数", "问题": "蓝牙耳机续航多久",
     "关键词": ["续航", "充电", "电量", "能用多久"],
     "答案": "单次充电续航 8 小时，配合充电仓总续航 30 小时；充电 1.5 小时可充满。"}
  ],
  "questions": [{"买家": "买家A", "问题": "耳机充一次电能用多久？"}]
}
```

**输出**（脚本实跑，12 问命中 11，命中率 91.7%）：

| 买家 | 买家问题 | 命中条目 | 匹配度 | 置信度 | 标准答复 |
|---|---|---|---|---|---|
| 买家A | 耳机充一次电能用多久 | KB-06 | 0.64 | 高 | 单次充电续航 8 小时… |
| 买家J | 退款要几天才能到账 | KB-13 | 0.606 | 中 | 退款审核通过后 1-3 个工作日… |
| 买家L | 可以帮我定制刻字吗 | 未命中 | 0.0 | — | 记入知识缺口 |

知识缺口：`可以帮我定制刻字吗` → 最相近条目「拆封后还能退吗」，最高匹配度 0.0，缺口类型「知识库无对应条目」。
