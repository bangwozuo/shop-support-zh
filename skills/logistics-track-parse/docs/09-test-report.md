## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 关键词归一化 | 覆盖主流承运商高频节点，长尾口语描述可能落到默认「运输中」，需模型复核 |
| 停滞阈值可调 | `stale_hours` 默认 72，可针对生鲜等高时效品类下调 |
| 无真实查件能力 | 脚本不调承运方接口；`shipments` 由用户导出或官方 API 提供 |
| 丢件判定 | 脚本只能标「异常」，丢件/赔付须承运方出险，脚本不越权 |
