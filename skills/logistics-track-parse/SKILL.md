# 物流跟踪解读

把一串原始物流轨迹翻译成买家能看懂的**当前状态 + 下一步**，把需要主动介入的**异常件**挑出来。

不做的事：不查库、不猜轨迹、不承诺到货时间；丢件/赔付必须由承运方出险。

## 能力描述

1. **状态归一化**：任意承运商口语节点 → 六态（待揽收/已揽收/运输中/派件中/已签收/异常件）。
2. **停滞计算**：停滞小时 = `now − 最后事件时间`，保留 0.1 小时。
3. **异常判定**：非已签收且停滞 ≥ 72h → 「超 72 小时无更新」；命中退回/拒收/滞留/超区/丢失 → 「轨迹异常」。
4. **话术映射**：六态各有标准话术骨架，异常件承诺 24 小时内答复。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shipments` | array | ✅ | 运单数组，每项含 `运单号`/`承运商`/`订单号`/`事件[]`（事件含 `时间`/`描述`/`地点`） |
| `now` | string | ⬜ | 基准时间 `YYYY-MM-DD HH:MM`，用于算停滞；缺省取全量事件最晚时间 |
| `stale_hours` | number | ⬜ | 停滞告警阈值，默认 `72` |

## 输出规格

- `summary`：运单总数 / 正常件 / 异常件 / 异常率 / 停滞阈值小时 / 基准时间
- `shipments`：逐单解读（运单号 / 承运商 / 当前状态 / 最后更新 / 停滞小时 / 是否异常 / 异常类型 / 话术建议）
- `anomalies`：异常件台账（需主动介入）

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供 `shipments`（含事件的运单数组），可另给 `now`、`stale_hours`
4. 得到分状态解读 + 异常件台账

### 方式二：带脚本（归一化 + 产出 Excel/PNG）

```bash
python3 <SKILL_DIR>/scripts/logistics_parse.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/logistics_parse.py --demo          # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/物流轨迹解读.xlsx` | 轨迹解读（异常行标红）/ 异常件台账 / 事件明细 / 话术建议 |
| `out/物流状态分布.png` | 在途运单当前状态分布柱状图 |
| `out/logistics.json` | 机器可读结果，供智能体读取 |

**分工**：脚本做**状态归一化与异常判定**（不漏、可复现）；模型做**共情话术与多轮沟通**。话术中的数值以脚本输出为准。

## 边界（不做的事）

- ❌ 不编造未出现的轨迹节点，不承诺「明天到」这类到货时间
- ❌ 不把「无轨迹」直接判为丢件、不承诺赔付（须承运方出险）
- ❌ 不泄露快递员手机号、买家地址（脱敏后再输出）
- ❌ 不贬损承运商（不用「最慢」「最差」）
- ❌ 轨迹数据不得爬取需登录的私密数据

## 调用示例

**输入**（`examples/input.json` 节选）：

```json
{
  "now": "2026-09-30 09:00",
  "stale_hours": 72,
  "shipments": [
    {"运单号": "SF1380001112223", "承运商": "顺丰", "订单号": "TB20260925001", "事件": [
      {"时间": "2026-09-29 19:05", "描述": "快件正在派送中，快递员小王 138****", "地点": "上海浦东"}
    ]}
  ]
}
```

**输出**（脚本实跑，6 单 3 异常）：

| 运单号 | 当前状态 | 停滞小时 | 是否异常 | 异常类型 |
|---|---|---|---|---|
| SF1380001112223 | 派件中 | 13.9 | 正常 | — |
| YT7600123456789 | 运输中 | 95.3 | ⚠️ 异常 | 超 72 小时无更新 |
| ZTO5500987654321 | 异常件 | 88.5 | ⚠️ 异常 | 轨迹异常（退回/超区）；超 72 小时无更新 |
| EMS9988776655443 | 运输中 | 263.0 | ⚠️ 异常 | 超 72 小时无更新 |

整体异常率 **50.0%**，异常件建议话术统一为「已主动联系承运方核查，24 小时内答复」。
