# 使用示例

以下示例的输入均为**真实可跑数据**，输出为把 `prompt.txt` 全量作为系统提示词后的应答结果。

---

## 示例 1：超时未发货 + 威胁投诉（L2 → 升三线）

**输入**（`examples/input.json`）：

```json
{
  "question": "都等三天了还不发货！问客服就一句「亲亲稍等」，太敷衍了吧，再这样我就退款投诉了",
  "context": "订单 TB20260925008，9 月 27 日下单保温杯，承诺 48 小时内发出，现已超时约 24 小时",
  "persona": "亲切、专业、不卑不亢的店铺客服"
}
```

**输出**：

| 项 | 内容 |
|---|---|
| 情绪等级 | L2 明显不满（命中「等三天」「太敷衍了吧」） |
| 是否升级 | 转三线主管（触发原因：命中「投诉」） |
| 四段回复（节选） | 「真的很抱歉，让您等了三天还只收到一句『稍等』…给您两个办法：① 加急催仓 2 小时内更新物流 ② 原路退款并补 5 元券…」 |

**整改前**：原示例对「这个多少钱？」都能答成安抚话术，且情绪表是空壳。
**整改后**：情绪按表述分级、升级按硬规则触发、回复按四段结构落地。

## 示例 2：L3 愤怒，只谈解决不辩解

**输入**：

```json
{
  "question": "你们发的什么垃圾货！用了两天就开胶，还删我评论？太气了！",
  "persona": "亲切、专业、不卑不亢的店铺客服"
}
```

**输出**：

| 项 | 内容 |
|---|---|
| 情绪等级 | L3 愤怒（命中「气」「垃圾」） |
| 禁语检查 | 未出现「这是规定」「没办法」；未纠正买家措辞 |
| 回复（节选） | 「非常抱歉让您遇到开胶的问题，这确实不该发生…我马上帮您走质量问题换新，运费我们承担，24 小时内给您换货单号…」 |
| 升级判断 | 转三线主管（情绪 L3；且买家提到「删评论」涉及评价纠纷） |

**要点**：愤怒时不摆规则、不讲道理；先认责、只谈解决，动作要具体到时限。

## 示例 3：L0 中性，别过度道歉

**输入**：

```json
{
  "question": "想问下这个保温杯能放冰块吗，另外发货要几天？"
}
```

**输出**：

| 项 | 内容 |
|---|---|
| 情绪等级 | L0 中性 |
| 回复（节选） | 「可以的，杯口 4.5cm 能放普通冰块；现货 48 小时内发出，我帮您备注优先发货～」 |
| 升级判断 | 否 |

**要点**：中性咨询加一句轻共情即可，过度道歉（「非常非常抱歉给您带来不便」）反而显得假、拉低信任。

---

## 示例 4：无 persona 时的默认人设

未提供 `persona` 时，默认「亲切、专业、不卑不亢」，不谄媚、不冷漠；任何情况下不承诺
超出店铺授权（退款/赔付/加急）的时限与金额。
