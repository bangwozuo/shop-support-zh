# 退换货政策应答

把**店铺政策 + 平台规则**准确翻译成买家能懂的答复，明确**谁承担运费、多久到账、下一步怎么操作**。

不做的事：不做责任判定以外的越权承诺、不替店长拍板赔付。

| 字段 | 值 |

## 能力描述

1. **可退判定**：7 天无理由（《消法》第 25 条）+ 三包质量问题，先判时限再判例外。
2. **例外识别**：定制、鲜活易腐、数字化商品、拆封影响二次销售的贴身/密封类等不适用无理由。
3. **运费责任**：质量问题/发错漏发 → 店铺承担；7 天无理由 → 买家承担（有运费险按保险）。
4. **到账口径**：审核通过后 1–3 个工作日退回原支付渠道（按平台）。
5. **平台差异**：淘宝/天猫、抖店、拼多多、小红书各有规则，答复前先认平台。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `question` | string | ✅ | 买家售后问话 |
| `context` | string | ⬜ | 平台/订单号/类目/下单签收时间/是否拆封/有无质量问题/运费险 |
| `persona` | string | ⬜ | 店铺售后政策与可承诺范围 |

## 输出规格

- `reply`：可直接发送的回复（四段结构，≤ 180 字）
- `policy`：政策判定（平台 / 情形 / 是否可退换 / 运费责任 / 到账时效）
- `escalate`：升级判断（否 / 转二线售后 / 转主管 + 触发原因）

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供 `question`（售后问话），尽量补 `context`（平台、签收时间、是否拆封、质量问题）
4. 得到话术 + 政策判定 + 升级判断

### 方式二：在平台导入

## 边界（不做的事）

- ❌ 不承诺超出平台规则与店铺政策的赔付、退换范围
- ❌ 不用「概不退换」「一经售出概不负责」等违反法定权利的表述
- ❌ 不诱导买家删差评、改好评、撤诉
- ❌ 不泄露买家个人信息
- ❌ 不引导站外退款，不承诺"私下转账退款"
- ❌ 涉及资金的退款/赔付只出草稿，不执行

## 调用示例

**输入**（`examples/input.json`）：

```json
{
  "question": "我收到的保温杯杯盖有划痕，想退货，运费谁出？",
  "context": "淘宝；订单 TB20260923011；89 元；9 月 25 日签收（第 5 天）；杯盖划痕属质量问题；已投保运费险",
  "persona": "质量问题包来回运费，支持 7 天无理由，退款审核 24h 内，到账 1–3 个工作日"
}
```

**输出**（节选）：

| 项 | 内容 |
|---|---|
| 情形 | 质量问题，签收第 5 天仍在 7 天内 |
| 是否可退换 | 可退（不受无理由例外限制） |
| 运费责任 | **店铺承担**（来回运费） |
| 到账时效 | 审核通过后 1–3 个工作日原路到账 |
| 是否升级 | 否（责任明确、金额在授权内） |
