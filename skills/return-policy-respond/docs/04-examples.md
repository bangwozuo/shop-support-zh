# 使用示例

以下示例的输入均为**真实可跑数据**，输出为把 `prompt.txt` 全量作为系统提示词后的应答结果。

---

## 示例 1：质量问题退货，运费谁出（店铺承担）

**输入**（`examples/input.json`）：

```json
{
  "question": "我收到的保温杯杯盖有划痕，想退货，运费谁出？",
  "context": "淘宝；订单 TB20260923011；89 元；9 月 25 日签收（第 5 天）；杯盖划痕属质量问题；已投保运费险",
  "persona": "质量问题包来回运费，支持 7 天无理由，退款审核 24h 内，到账 1–3 个工作日"
}
```

**输出**：

| 项 | 内容 |
|---|---|
| 情形 | 质量问题，签收第 5 天仍在 7 天内 |
| 是否可退换 | 可退（不受无理由例外限制） |
| 运费责任 | **店铺承担**（来回运费） |
| 到账时效 | 审核通过后 1–3 个工作日原路到账 |
| 四段回复（节选） | 「…杯盖划痕属于质量问题，来回运费由我们承担。您点『申请售后 → 退货退款』，选原因『质量问题』，上传 1 张照片即可…24 小时内审核，1–3 个工作日到账…」 |

**整改前**：原示例对价格咨询都能答退换货，且把"运费谁出"这个核心问题完全回避。
**整改后**：先判时限与例外，再定运费责任，最后给到账口径——三个问题一次答清。

## 示例 2：7 天无理由，运费买家承担

**输入**：

```json
{
  "question": "这个耳机听着不太喜欢，能退吗，运费呢？",
  "context": "抖店；订单 D20260928009；399 元；9 月 29 日签收（第 2 天）；耳机已拆封但完好、不影响二次销售；无质量问题",
  "persona": "7 天无理由，无质量问题时退货运费买家承担"
}
```

**输出**：

| 项 | 内容 |
|---|---|
| 情形 | 7 天无理由（第 2 天，商品完好） |
| 是否可退换 | 可退 |
| 运费责任 | **买家承担**（无质量问题；如有运费险按保险赔付） |
| 行动 | 订单页申请「退货退款」，寄回后 1–3 个工作日到账 |

**要点**：与示例 1 对照——同为退货，运费责任因"质量问题"与"无理由"而完全相反。

## 示例 3：无理由例外商品（拆封贴身用品）

**输入**：

```json
{
  "question": "这个内衣我拆了吊牌试了下不太合适，能无理由退吗",
  "context": "淘宝；类目：贴身衣物；已拆吊牌且试穿",
  "persona": "拆封后影响二次销售的贴身类不支持无理由退货"
}
```

**输出**：

| 项 | 内容 |
|---|---|
| 情形 | 无理由例外（拆封影响二次销售的贴身类） |
| 是否可退换 | 不支持 7 天无理由；如存在质量问题可另行处理 |
| 回复（节选） | 「很抱歉，贴身类商品拆封试穿后不支持无理由退货（影响二次销售）；如果是尺码或质量有问题，请拍照，我帮您走质量售后…」 |

**要点**：识别例外，同时**不用"概不退换"**，并保留质量问题的维权通道。

---

## 示例 4：信息不足时先追问

未提供签收时间 / 是否拆封 / 有无质量问题时，按 prompt.txt 规则**列清单让买家补**，
不臆测"肯定能退/不能退"。缺失项一般含：签收日期、是否拆封、问题照片、订单号。
