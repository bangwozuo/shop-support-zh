# 转人工分流

对每通会话判定**该由谁、在多久内**处理，产出能让人直接接管的**交接摘要**。

不做的事：不回答买家、不承诺补偿、不替接管人下结论。

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_ecom_02_sk06` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 店铺客服官 |
| 能力族 | 分类判断型 · 分流路由 |
| 复杂度 | `S` |
| 阶段 | `P0` |
| 复用度 | ★★★★★（所有接待类复用） |
| 资产形态 | 纯提示词 + 可选 Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **工单分类**：按分类树匹配（价格 → 退换货 → 发票 → 尺码不合适 → 质量 → 物流 → 其他）。
2. **情绪分级**：L0 中性 / L1 轻微不满 / L2 明显不满 / L3 愤怒 / L4 极端威胁。
3. **升级判定**：命中投诉/差评/12315/平台介入/工商/消协/曝光/起诉/律师/举报/维权 → 三线。
4. **三层路由 + SLA**：一线自助（首响 <30s）/ 二线人工（接管 <3min）/ 三线主管（主管签字）。
5. **交接摘要**：结构化一句话，供接管人直接使用。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `conversations` | array | ✅ | 会话数组，每项含 `会话ID`/`买家`/`订单金额`(可选)/`消息[]`（消息含 `角色`/`内容`） |

## 输出规格

- `summary`：会话总数 / 一线自助 / 二线人工 / 三线（主管）/ 人工介入占比 / 触发升级信号数
- `routes`：分流台账（会话ID / 买家 / 主分类 / 情绪等级 / 升级信号 / 分流层级 / 接管时限 / 方案时效 / 交接摘要）
- `signals`：升级信号明细（触发三线的会话）

## 使用步骤

### 方式一：纯提示词（最快，任意平台）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 新建对话，把 `prompt.txt` 的**全部内容**粘贴为系统提示词
3. 提供 `conversations`（会话数组）
4. 得到分层路由结果与交接摘要

### 方式二：带脚本（分类/情绪/升级判定 + 产出 Excel/PNG）

```bash
python3 <SKILL_DIR>/scripts/handoff_route.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/handoff_route.py --demo          # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/分流台账.xlsx` | 分流台账（三线行标红）/ 分类分布 / SLA对照 / 升级信号明细 |
| `out/分流层级分布.png` | 三层分流分布柱状图 |
| `out/handoff.json` | 机器可读结果，供智能体读取 |

**分工**：脚本做**分类与升级判定**（不漏、不降级）；模型做**交接摘要润色与安抚措辞**。摘要中的层级、时限以脚本输出为准。

## 边界（不做的事）

- ❌ 带「投诉/差评/12315/平台介入」的会话不得留在二线，必须升三线
- ❌ 不在摘要里承诺赔付；分流不是答复
- ❌ 不编造会话里没有的订单号、金额、已做动作
- ❌ 不泄露买家个人信息
- ❌ 不生成压制投诉、诱导删差评的内容

## 调用示例

**输入**（`examples/input.json` 节选）：

```json
{
  "conversations": [
    {"会话ID": "C-1005", "买家": "买家E", "订单金额": 399,
     "消息": [{"角色": "买家", "内容": "我要退款，这个耳机左耳没声音，太差了，再不处理我就投诉到12315！"}]}
  ]
}
```

**输出**（脚本实跑，10 会话：一线 5 / 二线 2 / 三线 3）：

| 会话ID | 主分类 | 情绪等级 | 升级信号 | 分流层级 | 接管时限 |
|---|---|---|---|---|---|
| C-1001 | 物流 | L1 轻微不满 | — | 一线自助 | AI/自助即时 |
| C-1002 | 质量 | L2 明显不满 | — | 二线人工 | < 3 分钟 |
| C-1005 | 退换货 | L3 愤怒 | 投诉、12315 | 三线（主管） | < 3 分钟 |
| C-1010 | 质量 | L3 愤怒 | — | 三线（主管） | < 3 分钟 |

交接摘要样例：
> `[C-1005] 主诉「退换货」，情绪 L3 愤怒；命中升级信号：投诉、12315；路由至三线（主管）；接管时限 < 3 分钟，方案时效 24 小时内给方案，主管签字。`
