## 三、边界与已知限制

| 限制 | 说明 |
|---|---|
| 关键词分类 | 基于词表匹配；反讽、隐含表达可能落「其他」，需模型复核 |
| 情绪词表 | 覆盖高频表达；方言/网络新词需持续维护 |
| 分类互斥 | 一条会话只取一个主分类，跨类时按「价格>质量>物流」优先，可能与人工判断有差 |
| 不产生答复 | 本技能只做路由，实际安抚话术由 `emotion-detect-appease` 等承接 |
